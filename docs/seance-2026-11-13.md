## Déployer la démo Ludus (environ 30 minutes, déploiement compris)

1. Vérifier les templates : `ludus templates list` (il faut `debian-12-x64-server-template`).
2. Charger la config et déployer :
   ```bash
   ludus range config set -f ludus/range-config-demo.yml
   ludus range deploy
   ludus range logs -f
   ```
3. Récupérer les IP avec `ludus range status`, puis se connecter aux VM (via le WireGuard Ludus ou la console Proxmox, avec les identifiants par défaut des templates indiqués dans la doc Ludus).
4. Sur **MM01** :
   ```bash
   sudo ./install-mattermost.sh
   ./setup-mattermost.sh
   ```
5. Sur **PC-CONS01** et **PC-CONS02** : `sudo apt install -y jq curl netcat-openbsd`, puis `export MM_URL=http://10.X.20.10:8065`.

## Scénario de démo (3 minutes)

1. Sur PC-CONS01 : `./demo-post.sh conseiller1 "Réunion d'agence à 15h"`
2. Sur PC-CONS02 : `./demo-post.sh conseiller2 --lire` affiche le message.
3. Sur PC-CONS02 : `./demo-post.sh conseiller2 "Bien reçu"`, puis relecture depuis PC-CONS01.
4. Montrer le filtrage réseau depuis un client :
   - `nc -zv 10.X.20.10 8065` réussit (flux autorisé)
   - `nc -zv -w 3 10.X.20.10 22` échoue (refusé par la règle inter-VLAN)
5. Montrer la config `network:` du range pour faire le lien avec la matrice des flux de l'architecture.
